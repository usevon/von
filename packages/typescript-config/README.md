# @usevon/typescript-config

Shared TypeScript configuration for the Von monorepo.

## Usage

Extend in your `tsconfig.json`:

```json
{
  "extends": "@usevon/typescript-config"
}
```

Builds on `@tsconfig/bun` with overrides for declaration file output and monorepo package builds.
