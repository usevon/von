## Von vs Svix

Svix is a webhook sending service focused on outbound delivery. Von covers similar ground but adds several features Svix does not offer.

**Where Von differs:**

- **Inbound forwarding.** Von can receive webhooks from third-party providers and forward them to your app with retries and circuit breakers. Svix is outbound only.
- **Payload versioning.** Von lets you define per-version transforms (rename, remove, add defaults) so older endpoint consumers keep receiving the format they expect. Svix has no payload transformation.
- **Circuit breakers.** Von automatically stops sending to endpoints that fail repeatedly, then probes them after a cooldown period. Svix disables endpoints after failures but does not have the three-state circuit breaker pattern with automatic recovery.
- **Local dev tunnels.** The Von CLI includes a built-in tunnel for forwarding webhooks to localhost during development. Svix requires a separate tool like ngrok.
- **React SDK.** Von ships SWR-based hooks for managing endpoints and events from React apps.
- **Full self-hosting.** Von's entire stack (API, worker, dashboard) is open source and self-hostable. Svix open-sources the server but the management console is proprietary.

**Where Svix is ahead:**

- More language SDKs (Python, Go, Java, Ruby, Kotlin, C#)
- Longer track record in production
- Built-in management UI (Svix Play)
- Operational transformation webhooks

## Von vs Hookdeck

Hookdeck is a managed webhook gateway focused on receiving and routing inbound webhooks. It does not support sending outbound webhooks.

**Where Von differs:**

- **Outbound webhooks.** Von handles both sending and receiving. Hookdeck is inbound only.
- **Self-hosting.** Von can be fully self-hosted. Hookdeck is cloud-only.
- **Payload versioning.** Von transforms payloads per endpoint version. Hookdeck has request transformations but not versioned schemas.
- **Circuit breakers.** Von has automatic circuit breaking with three-state recovery. Hookdeck has rate limiting and retries but not circuit breakers.
- **Unified platform.** With Von, your outbound and inbound webhooks share the same API keys, dashboard, and SDKs.

**Where Hookdeck is ahead:**

- Visual workflow builder for routing and filtering
- More inbound source integrations
- Event filtering and transformation UI
- Longer history of inbound-specific features

## When to choose Von

Von is a good fit when you need:

- Both outbound and inbound webhooks in one platform
- Full self-hosting with no vendor lock-in
- Payload versioning for evolving webhook schemas
- Circuit breakers for automatic endpoint health management
- Local development tunnels without third-party tools
