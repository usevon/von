# Von Documentation

Welcome to the Von documentation. Von provides reliable webhook infrastructure for your applications, handling delivery, retries, and monitoring so you can focus on building your product.

## Quick Start

Get started with Von in minutes:

<Row>
  <Col>
    ### 1. Install the SDK

    Add the Von SDK to your project using your preferred package manager.

    ### 2. Configure your endpoint

    Set up your webhook endpoint in the Von dashboard or via the API.

    ### 3. Send webhooks

    Use the SDK to send webhooks to your configured endpoints.
  </Col>
  <Col sticky>
    <CodeGroup>
      <CodeGroupTab title="npm" value="npm">
```bash
npm install @usevon/sdk
```
      </CodeGroupTab>
      <CodeGroupTab title="pnpm" value="pnpm">
```bash
pnpm add @usevon/sdk
```
      </CodeGroupTab>
      <CodeGroupTab title="bun" value="bun">
```bash
bun add @usevon/sdk
```
      </CodeGroupTab>
    </CodeGroup>
  </Col>
</Row>
