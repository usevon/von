## Provider setup

Wrap your app with `VonProvider` to configure authentication and the API URL.

### API key auth

For applications using the SDK directly:

```tsx
import { VonProvider } from "@usevon/react";

function App() {
  return (
    <VonProvider apiUrl="https://api.usevon.com" apiKey="von_prod_xxx">
      <Dashboard />
    </VonProvider>
  );
}
```

### Session cookie auth

For the Von dashboard or apps that share a session:

```tsx
<VonProvider apiUrl="/api" useSession>
  <Dashboard />
</VonProvider>
```

<Properties>
  <Property name="apiUrl" type="string">
    Defaults to `"/api"`.
  </Property>
  <Property name="apiKey" type="string">
    Bearer token for API key auth.
  </Property>
  <Property name="useSession" type="boolean">
    Use cookie-based session auth instead of a Bearer token.
  </Property>
</Properties>

## Hooks

All hooks are imported from the `@usevon/react/hooks` subpath. They return SWR-based state with automatic caching and revalidation.

### useEndpoints

Fetches the list of outbound webhook endpoints.

```tsx
import { useEndpoints } from "@usevon/react/hooks";

function EndpointList() {
  const { endpoints, isLoading, refresh, mutate } = useEndpoints();

  if (isLoading) return <div>Loading...</div>;

  return (
    <ul>
      {endpoints.map((ep) => (
        <li key={ep.id}>{ep.url}</li>
      ))}
    </ul>
  );
}
```

### useInbound

Fetches the list of inbound endpoints.

```tsx
import { useInbound } from "@usevon/react/hooks";

function InboundList() {
  const { endpoints, isLoading } = useInbound();

  if (isLoading) return <div>Loading...</div>;

  return (
    <ul>
      {endpoints.map((ep) => (
        <li key={ep.id}>{ep.name}: {ep.forwardUrl}</li>
      ))}
    </ul>
  );
}
```

### useWebhooks

Fetches the list of webhook events.

```tsx
import { useWebhooks } from "@usevon/react/hooks";

function EventLog() {
  const { events, isLoading } = useWebhooks();

  if (isLoading) return <div>Loading...</div>;

  return (
    <ul>
      {events.map((evt) => (
        <li key={evt.id}>{evt.eventType}</li>
      ))}
    </ul>
  );
}
```

## Return values

All three hooks return the same shape:

| Property | Type | Description |
| --- | --- | --- |
| data | `T[]` | The fetched items (`endpoints`, `events`, etc.) |
| `nextCursor` | `string \| null` | Cursor for the next page |
| `isLoading` | `boolean` | True during initial fetch |
| `isRefreshing` | `boolean` | True during revalidation after initial load |
| `error` | `Error \| undefined` | Fetch error if any |
| `refresh` | `() => void` | Trigger SWR revalidation |
| `mutate` | `KeyedMutator` | SWR mutate for optimistic updates |

## Optimistic updates

Use `mutate` for instant UI feedback:

```tsx
const { endpoints, mutate } = useEndpoints();

async function pause(id: string) {
  mutate(
    { endpoints: endpoints.map((e) =>
      e.id === id ? { ...e, status: "paused" } : e
    ), nextCursor: null },
    { revalidate: false }
  );

  await fetch(`/api/endpoints/${id}`, {
    method: "PATCH",
    body: JSON.stringify({ status: "paused" }),
  });

  mutate();
}
```

## Custom hooks with createResource

Build your own hooks using the `createResource` factory:

```tsx
import { createResource } from "@usevon/react/hooks";

const useVersions = createResource("versions", "versions");
```

This creates a hook with the same return shape as the built-in hooks.
