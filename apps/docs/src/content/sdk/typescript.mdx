## Configuration

```typescript
import { Von } from "@usevon/sdk";

const von = new Von({
  baseUrl: "https://api.usevon.com",
  apiKey: "von_prod_xxx",
});
```

Both are optional, and the SDK falls back to environment variables:

| Option | Environment variable | Default |
| --- | --- | --- |
| `baseUrl` | `VON_BASE_URL` | `http://localhost:8080` |
| `apiKey` | `VON_API_KEY` | none |

## Endpoints

```typescript
const { data } = await von.endpoints.create({
  url: "https://your-app.com/webhooks",
  events: ["order.*"],
  maxAttempts: 6,
});

const { data: list } = await von.endpoints.list();

const { data: ep } = await von.endpoints.get("ep_xxx");

await von.endpoints.update("ep_xxx", { status: "paused" });

await von.endpoints.delete("ep_xxx");
```

### Test delivery

```typescript
await von.endpoints.test("ep_xxx", {
  eventType: "von.test",
  payload: { message: "ping" },
});
```

### Secret rotation

```typescript
const { data } = await von.endpoints.rotateSecret("ep_xxx");

await von.endpoints.clearPreviousSecret("ep_xxx");
```

## Webhooks

### Send an event

```typescript
const { data: event } = await von.webhooks.send({
  eventType: "order.created",
  payload: { orderId: "123" },
  idempotencyKey: "order-123-v1",
  endpointIds: ["ep_xxx"],
});
```

### Batch send

```typescript
const { data } = await von.webhooks.sendBatch({
  events: [
    { eventType: "order.created", payload: { orderId: "1" } },
    { eventType: "order.created", payload: { orderId: "2" } },
  ],
});
```

### Query events

```typescript
const { data } = await von.webhooks.list({
  eventTypes: ["order.*"],
  sort: "desc",
  limit: 50,
});
```

### Get an event

```typescript
const { data: event } = await von.webhooks.get("evt_xxx");
```

### Deliveries and replay

Deliveries, attempt history, and replay are available over HTTP and do not yet have SDK methods:

```text
GET  /webhooks/events/:id/deliveries
GET  /webhooks/deliveries/:id/attempts
POST /webhooks/events/:id/replay
POST /webhooks/events/replay
```

## Versions

Versions are keyed by their version string rather than an id.

```typescript
await von.versions.create({
  version: "2025-01-15",
  transforms: {
    "order.created": {
      rename: { "line_items": "items" },
      remove: ["internal_notes"],
    },
  },
});

const { data: list } = await von.versions.list();

const { data: version } = await von.versions.get("2025-01-15");

await von.versions.update("2025-01-15", {
  transforms: { "order.created": { remove: ["debug"] } },
});

await von.versions.delete("2025-01-15");
```

## Webhook verification

The SDK exports a standalone `verifyWebhook` function for consumers receiving Von webhooks:

```typescript
import { verifyWebhook, WebhookVerificationError } from "@usevon/sdk";

const event = verifyWebhook(rawBody, signatureHeader, secret);
```

See [Verifying Signatures](/verification) for the full guide.

## Error handling

Every method returns `{ data, error, status }`. The SDK never throws on HTTP errors:

```typescript
const { data, error, status } = await von.endpoints.get("invalid");

if (error) {
  console.error(status, error);
  return;
}

console.log(data.url);
```
