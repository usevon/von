## Configuration

```typescript
import { Von } from "@usevon/sdk";

const von = new Von({
  baseUrl: "https://api.usevon.com",
  apiKey: "von_prod_xxx",
});
```

Both fields are optional. The SDK reads from environment variables as a fallback:

| Option | Environment variable | Default |
| --- | --- | --- |
| `baseUrl` | `VON_BASE_URL` | `http://localhost:8080` |
| `apiKey` | `VON_API_KEY` | none |

## Endpoints

```typescript
const { data } = await von.endpoints.post({
  url: "https://your-app.com/webhooks",
  events: ["order.*"],
  maxAttempts: 6,
});

const { data: list } = await von.endpoints.get();

const { data: ep } = await von.endpoints["ep_xxx"].get();

await von.endpoints["ep_xxx"].patch({ status: "paused" });

await von.endpoints["ep_xxx"].delete();
```

### Test delivery

```typescript
await von.endpoints["ep_xxx"].test.post({
  eventType: "von.test",
  payload: { message: "ping" },
});
```

### Secret rotation

```typescript
const { data } = await von.endpoints["ep_xxx"].rotate.post();

await von.endpoints["ep_xxx"]["previous-secret"].delete();
```

## Webhooks

### Send an event

```typescript
const { data: event } = await von.webhooks.post({
  eventType: "order.created",
  payload: { orderId: "123" },
  idempotencyKey: "order-123-v1",
  endpointIds: ["ep_xxx"],
});
```

### Batch send

```typescript
const { data } = await von.webhooks.batch.post({
  events: [
    { eventType: "order.created", payload: { orderId: "1" } },
    { eventType: "order.created", payload: { orderId: "2" } },
  ],
});
```

### Query events

```typescript
const { data } = await von.webhooks.events.get({
  query: {
    eventTypes: ["order.*"],
    sort: "desc",
    limit: 50,
  },
});
```

### View deliveries

```typescript
const { data } = await von.webhooks.events["evt_xxx"].deliveries.get({
  query: { status: "failed" },
});
```

### Replay

```typescript
await von.webhooks.events["evt_xxx"].replay.post();

await von.webhooks.events.replay.post({
  since: "2025-01-01T00:00:00Z",
  status: "failed",
});
```

## Inbound

```typescript
const { data } = await von.inbound.post({
  name: "Stripe",
  provider: "stripe",
  forwardUrl: "https://your-app.com/stripe",
});

const { data: list } = await von.inbound.get();

await von.inbound["in_xxx"].patch({ status: "paused" });

await von.inbound["in_xxx"].delete();
```

## Versions

```typescript
await von.versions.post({
  version: "2025-01-15",
  transforms: {
    "order.created": {
      rename: { "line_items": "items" },
      remove: ["internal_notes"],
    },
  },
});

const { data: list } = await von.versions.get();

await von.versions["2025-01-15"].patch({
  transforms: { "order.created": { remove: ["debug"] } },
});

await von.versions["2025-01-15"].delete();
```

## Webhook verification

The SDK exports a standalone `verifyWebhook` function for consumers receiving Von webhooks:

```typescript
import { verifyWebhook, WebhookVerificationError } from "@usevon/sdk";

const event = verifyWebhook(rawBody, signatureHeader, secret);
```

See [Verifying Signatures](/verification) for the full guide.

## Error handling

Every method returns `{ data, error, status }`. The SDK never throws on HTTP errors:

```typescript
const { data, error, status } = await von.endpoints["invalid"].get();

if (error) {
  console.error(status, error);
  return;
}

console.log(data.url);
```
