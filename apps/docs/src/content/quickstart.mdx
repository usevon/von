# Getting Started

Send your first webhook with Von in under 5 minutes.

## Prerequisites

Before you begin, make sure you have:

- A Von account ([sign up here](https://usevon.com))
- Node.js 18+ installed
- Your API key from the [Von dashboard](https://usevon.com/dashboard)

## Setup

<Timeline>
  <TimelineItem title="Install the SDK">
    <CodeGroup>
      <CodeGroupTab title="bun">
```bash
bun add @usevon/sdk
```
      </CodeGroupTab>
      <CodeGroupTab title="npm">
```bash
npm install @usevon/sdk
```
      </CodeGroupTab>
      <CodeGroupTab title="pnpm">
```bash
pnpm add @usevon/sdk
```
      </CodeGroupTab>
    </CodeGroup>
  </TimelineItem>

  <TimelineItem title="Add your API key">
    Create a `.env` file in your project root and add your Von API key:

```bash
VON_API_KEY=von_live_xxxxxxxxxxxxx
```
  </TimelineItem>

  <TimelineItem title="Initialize the client">
```typescript
import { Von } from "@usevon/sdk";

const von = new Von({
  apiKey: process.env.VON_API_KEY,
});
```
  </TimelineItem>

  <TimelineItem title="Create an endpoint">
    An endpoint is where Von will deliver your webhooks.

```typescript
const endpoint = await von.endpoints.create({
  url: "https://your-app.com/webhooks",
  description: "Production webhook endpoint",
});
```
  </TimelineItem>

  <TimelineItem title="Send your first webhook">
```typescript
await von.webhooks.send({
  endpointId: endpoint.id,
  eventType: "user.created",
  payload: {
    userId: "user_123",
    email: "user@example.com",
    createdAt: new Date().toISOString(),
  },
});
```
  </TimelineItem>
</Timeline>
