# Quick Start

Send your first webhook with Von in under 5 minutes.

<PageActions />

## Prerequisites

1. A Von account ([create one for free](https://app.usevon.com/)).
2. Node.js 18 or later.
3. An API key from the [API Keys page](https://app.usevon.com/settings/api-keys).

## Setup

<Timeline>
  <TimelineItem title="Install the SDK">
    <CodeGroup>
      <CodeGroupTab title="bun">
```bash
bun add @usevon/sdk
```
      </CodeGroupTab>
      <CodeGroupTab title="npm">
```bash
npm install @usevon/sdk
```
      </CodeGroupTab>
      <CodeGroupTab title="pnpm">
```bash
pnpm add @usevon/sdk
```
      </CodeGroupTab>
    </CodeGroup>
  </TimelineItem>

  <TimelineItem title="Configure environment">
    Create a `.env` file and add your API key. The prefix determines the environment: `von_dev_` for development, `von_stg_` for staging, `von_prod_` for production.

```bash
VON_API_KEY=von_dev_xxxxxxxxxxxxx
```
  </TimelineItem>

  <TimelineItem title="Initialize the client">
```typescript
import { Von } from "@usevon/sdk";

const von = new Von({
  apiKey: process.env.VON_API_KEY,
});
```
  </TimelineItem>

  <TimelineItem title="Create an endpoint">
    The destination URL where Von delivers webhooks.

```typescript
const { data: endpoint } = await von.endpoints.create({
  url: "https://your-app.com/webhooks",
  description: "Production webhook endpoint",
});
```
  </TimelineItem>

  <TimelineItem title="Send a webhook">
```typescript
const { data: event } = await von.webhooks.send({
  eventType: "user.created",
  payload: {
    userId: "user_123",
    email: "user@example.com",
    createdAt: new Date().toISOString(),
  },
});
```
  </TimelineItem>

  <TimelineItem title="View in dashboard">
    Once sent, the webhook appears in the [Von dashboard](https://app.usevon.com/) for monitoring delivery status, response codes, and failures.
  </TimelineItem>
</Timeline>

<Note>
  Endpoint URLs must be publicly reachable HTTPS addresses. For local development, use the [CLI tunnel](/sdk/cli) to forward webhooks to localhost.
</Note>
