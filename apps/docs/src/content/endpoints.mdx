# Endpoints

Endpoints are the destination URLs where Von delivers your webhook events.

<PageActions />

## Creating an endpoint

Register a URL to receive webhooks, each endpoint gets a unique signing secret on creation.

```typescript
const { data: endpoint } = await von.endpoints.post({
  url: "https://your-app.com/webhooks",
  description: "Production webhook receiver",
});
```

<Note>
  Save the endpoint `secret` from the response as it is never shown again and can only be recovered by rotating the endpoint.
</Note>

## Configuration options

<Properties>
  <Property name="url" type="string" required>
    Public HTTPS destination, with private IPs, localhost, and cloud metadata endpoints blocked.
  </Property>
  <Property name="description" type="string">
    A display label.
  </Property>
  <Property name="status" type="string">
    `active` delivers normally, `paused` queues deliveries with a paused status, `disabled` skips deliveries entirely. Von automatically disables endpoints after 5 consecutive days of sustained delivery failures.
  </Property>
  <Property name="events" type="string[]">
    Event type patterns to subscribe to, where omitting or passing `null` receives all events and an empty array receives nothing.
  </Property>
  <Property name="version" type="string">
    Pins the endpoint to a payload version, applying its transforms before delivery.
  </Property>
  <Property name="maxAttempts" type="number">
    Total delivery attempts including the initial try. Range 1 to 10, defaults to 4.
  </Property>
  <Property name="timeoutMs" type="number">
    Response timeout in ms before the attempt is marked failed. Range 1000 to 60000, defaults to 30000.
  </Property>
</Properties>

## Event filtering

Endpoints subscribe to specific event types using pattern matching.

| Pattern | Matches |
| --- | --- |
| `order.created` | Exact match only |
| `order.*` | Any event starting with `order.` |
| `*.created` | Any event ending with `.created` |
| `*` | All events |

```typescript
const { data: endpoint } = await von.endpoints.post({
  url: "https://your-app.com/webhooks",
  events: ["order.*", "invoice.paid"],
});
```

## Updating an endpoint

```typescript
await von.endpoints["ep_xxx"].patch({
  description: "Updated description",
  events: ["order.*"],
  maxAttempts: 6,
});
```

All fields are optional and only the fields you include are updated.

## Test deliveries

Send a test webhook to the endpoint and review the resulting event and delivery in the dashboard.

```typescript
const { data } = await von.endpoints["ep_xxx"].test.post({
  eventType: "von.test",
  payload: { message: "Hello from Von" },
});
```

## Secret rotation

Rotate an endpoint's signing secret without downtime. During the rotation window, Von includes both the current and previous signatures so your consumer can verify with either key.

```typescript
const { data } = await von.endpoints["ep_xxx"].rotate.post();
```

The response includes the new `secret` and `previousSecret`, so once your consumer is updated to the new secret, clear the old one:

```typescript
await von.endpoints["ep_xxx"]["previous-secret"].delete();
```

During rotation the `X-Von-Signature` header contains two signatures:

```
t=1700000000,v1=<current_secret_hmac>,v2=<previous_secret_hmac>
```

## Deleting an endpoint

```typescript
await von.endpoints["ep_xxx"].delete();
```

Deleting an endpoint removes all associated delivery records.

## SSRF protection

Von validates endpoint URLs at creation and again at delivery time. The following are blocked:

- Private IP ranges
- Cloud metadata endpoints (`169.254.169.254`, `metadata.google.internal`)
- Non-HTTP(S) protocols

DNS is re-resolved at delivery time to catch rebinding attacks.

<Tip title="Testing locally">
  Localhost and private IPs are blocked as endpoint URLs, so use the [CLI tunnel](/sdk/cli) to get a public URL that forwards to your local server.
</Tip>
